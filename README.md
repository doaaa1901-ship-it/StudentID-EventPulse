# EventPulse API

EventPulse is a real-time event management platform backend built with Node.js, Express, MongoDB, and Socket.io. It provides user authentication, event management with filtering/pagination, registration limits, live announcements, input validation, and automated test coverage.

## Tech Stack
* **Runtime**: Node.js
* **Framework**: Express.js
* **Database**: MongoDB (Mongoose ORM)
* **Real-time WebSockets**: Socket.io
* **Validation**: express-validator
* **Security & Auth**: JWT, bcryptjs, express-mongo-sanitize
* **Testing**: Jest, Supertest
* **Documentation**: Swagger UI (`swagger-ui-express`, `swagger-jsdoc`)
* **Deployment**: Vercel
